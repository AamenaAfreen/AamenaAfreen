## Featured Projects
 - **[Evaluating If a Model Knows What It Doesn't Know](https://github.com/AamenaAfreen/lm-evaluation-harness)** - Master's capstone. Extended EleutherAI's lm-evaluation-harness with 68 tasks across 5 benchmarks (TruthfulQA, GPQA, MedHALT, MMLU, PubMedQA) and 4 production LLMs. Embedding an asymmetric scoring rule in  the prompt cut GPT-4o mini's wrong-answer rate on GPQA Diamond from 91% to 16% and flipped Gemini 2.0 Flash from net-harmful (−0.53) to net-beneficial (+0.14), validated with 168 paired statistical tests and bootstrap CIs.

 - **[Multi-Agent LLM Coordination: A Codenames Study](https://github.com/AamenaAfreen/codemaster)** - Two LLM agents cooperating under hidden information: 1,765 games, all 36 prompt-strategy combinations on fixed seeds. Best pairing hit 96% vs. the published baseline's 94% on a ~50x cheaper model. Controlled ablation    isolated a self-critique failure mode — the uninformed agent's critique destroyed its own correct answers; removing it took win rate from 22% to 73%. Part of a co-authored AIIDE 2026 submission.
